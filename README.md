# KOBA - Night Time Resort Clothing Brand

A modern e-commerce website for KOBA, a luxury clothing brand inspired by night time resort aesthetics.

## Features

- Product catalog with filtering and search
- Shopping cart and checkout
- Shopify integration for payments
- Contact form
- Night time resort design aesthetic
- Responsive mobile design

## Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript
- **E-commerce**: Shopify
- **Hosting**: GitHub Pages / Vercel

## Project Structure

```
koba-clothing/
├── index.html
├── css/
│   └── style.css
├── js/
│   ├── main.js
│   └── shopify-config.js
├── images/
├── README.md
└── SETUP_GUIDE.md
```

## Getting Started

1. Clone the repository
2. Update Shopify API credentials in `js/shopify-config.js`
3. Customize the design and product catalog
4. Deploy to your hosting platform
